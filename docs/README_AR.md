# توثيق مشروع المتجر الإلكتروني

## نظرة عامة

واجهة برمجية (REST API) متكاملة لمتجر إلكتروني مبنية بـ **Laravel 13** و **Laravel Sanctum**. مصممة لتشغيل تطبيقات الجوال أو المواقع الإلكترونية مع لوحة تحكم منفصلة للإدارة. جميع المحتوى يدعم **ردودًا ثنائية اللغة (عربي / إنجليزي)** عبر معامل `local`.

---

## المميزات الرئيسية

### دعم اللغتين
كل محتوى (أسماء المنتجات، الأوصاف، الفئات، المتغيرات، الكوبونات، المدن، المناطق) مخزن كـ JSON بمفتاحين `en` و `ar`. يرسل العميل `local=en` أو `local=ar` ويستقبل البيانات مترجمة.

### نظام صلاحيات مزدوج
- **الأدمن** — تحكم كامل في المنصة (منتجات، طلبات، مستخدمين، إعدادات، كوبونات...)
- **المستخدم** — تصفح، طلب، إدارة العناوين، تطبيق كوبونات

المصادقة عبر Sanctum tokens مع middleware مخصص لكل دور (`AdminMiddleware` / `UserMiddleware`).

## الأقسام

### المنتجات
- إنشاء، قراءة، تعديل، حذف مع رفع صورة رئيسية (تُحوَّل تلقائيًا إلى WebP)
- دعم **المتغيرات** (مثل: المقاس، اللون) وكل متغير له **خيارات** بسعر مستقل
- إدارة **معرض الصور** — إضافة أو حذف صور متعددة لكل منتج
- نظام خصم بنطاق تاريخي (`discount_from` / `discount_to`)؛ يُحسب `final_price` و `is_discounted` تلقائيًا
- تبديل الحالة (نشط / غير نشط)

### الفئات
- هرمية — تدعم الفئات الرئيسية والفرعية (self-referencing)
- رفع صورة مع تحويل WebP
- تبديل الحالة

### الطلبات
- يُنشئ المستخدم طلبًا بمنتجات متعددة، لكل منها خيارات محددة
- الإجماليات (السعر، الخصم، خصم الكوبون، السعر النهائي) تُحسب من السيرفر — لا يمكن للعميل التلاعب بالأسعار
- إرفاق **صورة إيصال** (لطرق الدفع اليدوية)
- الأدمن يغير **حالة الطلب**: `pending → inprogress → delivered / faild_delivered / return`
- الأدمن يغير **حالة الدفع**: `pending → approve / reject`
- عرض تفصيلي كامل للطلب يشمل بيانات المستخدم، العنوان، طريقة الدفع، والمنتجات مع خياراتها

### الكوبونات
- كوبونات بكود مع نوعين للخصم: **نسبة مئوية** أو **قيمة ثابتة**
- حدود قابلة للضبط: إجمالي استخدام (`usage_limit`) وحد لكل مستخدم (`user_usage_limit`)
- صلاحية بنطاق تاريخي (`from` / `to`)
- حد أقصى اختياري للخصم (`max_discount`)
- `users_count` يُتتبع تلقائيًا — لا يمكن ضبطه يدويًا
- حماية من الإساءة: **3 محاولات كل 3 دقائق** لكل مستخدم على endpoint التحقق من الكوبون

### العناوين
- المستخدم يدير عناوينه الخاصة (إنشاء، قراءة، تعديل، حذف)
- كل عنوان مرتبط بـ **مدينة** و **منطقة**
- قوائم منسدلة للمدن والمناطق مع الترجمة
- رابط Google Maps يُولَّد تلقائيًا من `lat` و `lng`

### المدن والمناطق
- الأدمن يدير المدن والمناطق مع تبديل الحالة
- المنطقة تحمل سعر التوصيل المستخدم في حساب الطلب

### طرق الدفع
- الأدمن يدير طرق الدفع المتاحة مع أيقونة، وصف، وحالة
- المستخدم يرى الطرق النشطة فقط عند إنشاء الطلب

### الإعدادات
- إعدادات الموقع في صف واحد (اسم العلامة التجارية، الشعار، بيانات التواصل، روابط السوشيال ميديا، إحداثيات الخريطة، الحد الأدنى للطلب)
- ذكي: ينشئ سجلًا جديدًا إن لم يوجد، ويحدّث إن وُجد
- رفع الشعار مع تحويل WebP

### معالجة الصور (trait)
- جميع الصور المرفوعة تُحوَّل تلقائيًا إلى **WebP** بجودة 80%
- عمليات التحديث **تحذف الصورة القديمة** من التخزين قبل حفظ الجديدة
- دوال مخصصة: `upload_image`، `update_image_v2`، `uploadFile_v2`، `deleteImage`

## هيكل الـ API

| البادئة | الحماية | الوصف |
|--------|---------|-------|
| `/api/login` | بدون | المصادقة |
| `/api/user/home/*` | بدون | تصفح عام (فئات، منتجات) |
| `/api/user/orders/lists` | بدون | بيانات قوائم الطلبات |
| `/api/user/*` | `auth:sanctum + user` | إجراءات المستخدم (عناوين، طلبات، كوبونات) |
| `/api/admin/*` | `auth:sanctum + admin` | لوحة تحكم الأدمن |

## التقنيات المستخدمة

- **Laravel 13**
- **Laravel Sanctum** (مصادقة بالتوكن)
- **Intervention Image v3** (تحويل WebP)
- **MySQL** (مع أعمدة JSON للحقول متعددة اللغات)
- **Laravel Rate Limiter** (حماية كوبونات من الإساءة)
